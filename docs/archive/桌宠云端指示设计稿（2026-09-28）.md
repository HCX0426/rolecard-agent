## 1. 要解的两个问题，和一个共同前提

| 问题 | 用户会撞到的样子 |
|---|---|
| 连的是云端，桌宠上没有任何指示 | 侧栏写着「数据源：云端 · u1」，桌宠气泡里聊的也是云端那份 —— 但小窗上没有任何一个地方说得出"我现在连的是哪份"。数据**确实**跟着切了（`api.ts` 的 `apiBase()`），所以这不是泄漏，是"界面一致性"缺口 |
| 她最近怎么不找我 | 运行环境页有"为什么静默"那一格（`S-8` 已落地）、收件箱抽屉头部也有一行 —— 唯独桌宠小窗上没有。用户日常就是盯着桌宠的，查不到的地方等于没有 |

**共同前提（关键：两样数据都已经在桌宠手边，不需要新端点）**：

- 云端与否 = `lib/dataSource.ts` 的 `read()`（localStorage），`PetPage` 直接 import 就行；
- 静默原因 = `load()` 每 3 秒已经在调 `getReachouts()`，那份响应里**本来就有** `quiet: [{role_id, why, next_ok_at, streak, unread}]`，只是 `PetPage` 只取了 `items` 和 `unread_by_role` 没拿 `quiet`。

代价小，因为**没有任何新 API、没有新轮询** —— 纯粹是"已经在手边的两样，显示出来"。

## 2. 桌宠的空间长什么样

画布 560×520：收起态只有色片（88px 圆）和一个偶尔冒出的气泡；展开后是一块 **380 宽**的面板（最近几条 + 输入框）。顶栏是 09-27 被否过的（「那个横幅我感觉没必要」）—— 所以本稿的前提是：**不新增横幅，只动展开面板里已经存在的那块边距**。

## 3. 决策点 A：这格放哪、长什么样（三选一）

**A 方案 · 面板顶部一行极细状态条（推荐）**

```
┌ 爱莉希雅 · 主动找你 ─────────────────────────  ● 云端 · u1 ┐
│                                                              │
│  最近几条…（照旧）                                            │
```

- 一行小字（`text-[10px]`）：本机 = `● 本机`（绿点，几乎不显眼）；云端 = `☁ 云端 · u1`（天蓝点）。
- 就位在面板最顶：反正是**只读**的东西，点它不做任何事（切回本机在侧栏，桌宠不重复给第二个入口 —— 与「同一个开关只出现一次」同一条理）。
- 颜色沿用 `DataSourceSwitch` 那两口：`emerald`（本机）/ `sky`（云端），同一家族不新造色。

**B 方案 · 只在云端态显示**（最小）

- 本机态整行不出现 —— "连的是本机"是常态，天天挂一行绿色小字也是噪音。
- 桌面壳托盘里其实还有一行「数据源」，本机态看着它没有任何信息量。

**C 方案 · 不做云端指示，折叠进 title**（否决）

- 把"云端 · u1"塞进色片/面板的 `title`（hover 提示）—— 等于没有；用户查不到的东西还是查不到（与 `S-8` 那句"查不出来变成一眼看到"相反）。

## 4. 决策点 B：静默出口要不要一起放这行上

「她为什么没说话」在桌宠上的归宿，两个候选：

| 选项 | 样子 | 代价 |
|---|---|---|
| **放 A 方案那行的右侧**（推荐） | `☁ 云端 · u1` 已占一行，静默句放它右侧同一行：`… 云端 · u1 ｜ 距上次说话不足 66 分钟` | 复用 `lib/quiet.ts` 的 `QuietLine`（控制台收件箱抽屉同款三段式）—— 数据每 3 秒已在手 |

| 并入 title | hover 才见 | 同 C 方案的理由，不做 |

## 5. 折叠态怎么办

**不做**（两处都说清楚）：

- 收起态只有色片，没有可放文字的地方；把"云端"塞进色片圆圈里会跟首字抢字。
- 折叠时的场景是"她冒了条气泡"—— 用户看到的是**话**，不是数据源；想知道连的是哪份，展开面板一行就看到。
- 色片 `title` 已带名字与「连不上本地服务」，再堆一段云端态会糊。

## 6. 打开面板才显示，还是打开显示 + 常驻？

这条问的是**展开面板的注意力**：A 方案的状态条只在**展开且显示内容**时画（`expanded && showContent`）—— 与消息区同一条闸。否则"只显示最近一条"（`showContent=false`，托盘勾没内容）时，一行云端地址反而把"内容已隐藏"那半句话的意义混淆了。
