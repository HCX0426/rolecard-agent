## 一、技术栈总结

### 后端（Python 3.13，`src/rolecard_agent/`）

| 层 | 技术 | 说明 |
|---|---|---|
| API 框架 | FastAPI + uvicorn | 同步端点为主（线程池执行）；对话 SSE 走专属线程池，避免事件循环阻塞 |
| Agent 编排 | LangGraph 1.2.11 + LangChain 1.4.0 | 两节点循环（model↔tools）+ SQLite Checkpointer；必须成对锁版本；`AGENT_MAX_STEPS` 上限防工具循环无界 |
| 模型接入 | langchain-ollama / langchain-openai（经 `init_chat_model`） | 多后端同构（本地 Ollama + 任意 OpenAI 兼容云），回退链 ≤2，超时 120s（按客户端风格传参数） |
| 业务持久化 | SQLite（WAL + FK + busy_timeout，`ThreadLocalConnection` 按线程分发） | 单文件库 `data/sqlite/app.db`，业务表 + checkpoint + 审计；库代际机制防跨线程残留事务 |
| 向量检索 | Chroma（PersistentClient，1.5.9，新集合按 cosine 建）+ 自研 HashEmbedder / SiliconFlow bge-m3 / 重排 | 一个作用域一个集合；索引身份 = 摄入任务 id（非文件名）；删除连向量一起清；绝对相似度下限可配（默认关） |
| 校验/配置 | Pydantic v2 + 自研 `Settings.from_env`（环境变量驱动） | 依赖单一事实来源 pyproject.toml，requirements*.txt 是镜像 |
| 文档摄取 | pypdf（PDF）+ 标准库 zipfile/ElementTree（OOXML）+ 可插拔 OCR | PaddleOCR 在**独立 venv 子进程**（数据不出本机）；云端 OCR 需显式 key（未配绝不外发）；OOXML 禁止 DOCTYPE（XXE/bomb 加固）；上传 15MB 上限 |
| 可观测 | 自研 Tracer 门面（JSON lines，默认键控脱敏 + 8MB 轮转）+ 审计表（actor/action/target） | langsmith/langfuse 为预留（依赖已删，字段解析保留，见 config.py RESERVED_SETTINGS） |
| 质量工具 | pytest+pytest-cov（**457 用例**，阈值 85%，实测 86.77%）· ruff · **自研 check_consistency**（文档↔代码 **24 项断言**）· mypy（**56 文件 0 问题**） | 测试全离线铁律：LLM 一律注入脚本替身 |

## 二、部署方式与运行环境（现状 + 计划）

**现状（本机运行形态）**：
- `scripts/run_api.py` 起 uvicorn 单进程，绑 127.0.0.1:8000；前端 dist 由 FastAPI 静态托管（API 路由优先注册）
- 数据落 `data/`（SQLite + Chroma + uploads），已 gitignore；演示身份单用户
- 认证 `AUTH_MODE=off`（本地零配置）；模型默认后端 `local`，实际模型 **qwen3-vl:8b**（Ollama 127.0.0.1:11434），OCR 走**一行多用**（直接引用对话后端，不单独配视觉行）
- **运行环境页面可在线改并热生效**（2026-09-17）：联网总闸 / 域名白名单 / 搜索后端 / OCR / 嵌入与重排 / 超时与预算 / 思考模式等字段，保存即 `rebuild_runtime` 换装，无需重启；只读项（认证 / 观测 / 路径）需改 `.env` 重启

**v2.4 计划（现状 + 待办）**：
1. **Docker**：`python:3.13-slim` 镜像（dist 打进镜像），数据挂卷 `rolecard-data:/app/data`；**未实机 build 验证**（本机无 docker）
2. **认证切换**：部署时 `AUTH_MODE=on` + `AUTH_CREDENTIALS`/`AUTH_API_KEYS`（用法已写入 .env.example）；反代场景可配 `AUTH_TRUSTED_PROXIES`
3. **模型侧两形态**（同一份代码只改配置）：演示期可内网穿透回本机 Ollama；稳定版云服务器 + 云端 API 后端（MODEL_BACKENDS 切换）
4. **CI**：GitHub Actions（后端 lint+test+覆盖率 85%+一致性 / 前端 test+build）——⚠️ 仓库目前**无远端，CI 从未真实执行过**
5. 未规划项（部署前需补）：TLS/域名、限流、Docker 实机验证

## 三、项目结构与职责对应

| 模块 | 职责 | 对应功能 |
