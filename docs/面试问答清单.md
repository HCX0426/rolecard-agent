# 03 · 面试问答清单

> 状态：待填充。随开发进度边做边写，不要留到 Week 4 才补。
> 原则：每个问题都配一个**你真实做过的决策 + 取舍理由**，而不是背书式答案。

## 待覆盖的问题分类

### A. 技术选型
- 为什么用 LangGraph 而不是 LangChain 的 AgentExecutor / create_agent？
- LangGraph 相比"自己写个 while 循环调工具"多解决了什么问题？
- 为什么用 Ollama 而不是直接调 API？企业里会怎么替换？
- Chroma 和 SQLite 的分工边界是怎么定的？

### B. 状态与记忆
- 会话状态怎么持久化？thread_id 怎么和用户绑定？
- 短期记忆和长期记忆为什么必须分开？
- 摘要压缩会不会丢信息？医疗场景你怎么处理？

### C. 工具调用与权限
- 工具白名单在什么层面生效？为什么不在执行时拦截？
- 让 LLM 自己调用 switch_role 有没有安全风险？你怎么处理的？
- 工具失败重试怎么做的？重试 2 次这个数字怎么来的？

### D. 安全与合规
- 你怎么保证模型不给出医疗诊断？
- 提示词约束可靠吗？如果用户诱导它呢？
- 病历数据上传到 LangSmith 云端，合规上你怎么解释？
- AI 自动提取的指标可能出错，你做了什么？

### E. 工程化
- 分层之后层与层之间怎么通信？为什么不让 Agent 层直接写 SQL？
- 结构化数据和向量库的数据一致性怎么保证？（**这题很容易被问倒，提前想好**）
- 怎么定位一次"模型答错了"的请求？LangSmith 里你看哪些字段？
- 这套东西 QPS 上不去怎么办？生产要改哪些地方？

### F. 踩坑
- 遇到最难的问题是什么？怎么定位的？
