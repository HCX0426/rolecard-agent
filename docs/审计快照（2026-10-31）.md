## 五、开源参照汇总

- **chromadb "Nothing found on disk"**：chroma-core/chroma#7952（活跃 issue）；amikos-tech/chromadb-ops（社区口径：HNSW 损坏重建）。
- **Azure 缓存 503**："Ingress/egress is over the account limit (503)" 服务端限流；actions/toolkit 按 warning 处理；同类先例 moby/buildkit#2836。
- **vitest CI**：官方 Improving Performance / CLI sharding（blob reporter 跨机分片）——本仓 26s 量级暂不需要；vitest#9683（pool 选错 3×慢）。
- **tsc 缓存**：tsbuildinfo 键不当时静默跳真类型错——多数团队 CI 冷跑，本仓 22s 不值得引入。
- **electron 缓存**：electron-builder#1868（`~/.cache/electron` 持久化标准修法）；ELECTRON_BUILDER_CACHE 改值破坏 promise 缓存（#8480）。
- **Actions 版本线**：checkout v6 / setup-node v5 / setup-python v6 / upload-artifact v5（Node20→Node24）；浮动 tag 先 gh api 验存在性（setup-uv v10 教训）。
- **提示注入**：OWASP LLM Injector/注入防护 Cheat Sheet（定界/隔离模式，直接支撑 R1031-21）；llm-guard（已 archived，参照扫描点位不引依赖）；rebuff（canary token 思路）。
- **角色卡格式**：character-card-spec-v2 / ccv3 规范（PNG 同含 chara+ccv3 时读取方应**优先 ccv3**——本仓正好反着）；charactercardconverter.com 可当兼容性对照物。
- **数据导出/迁移**：Open WebUI（一键全量导出 + "数据库文件即备份"口径）；LibreChat（Data Controls 导出 + UPGRADING.md 备份纪律）。
- **检查点治理**：LangGraph `checkpointer.delete_thread()` / `prune()`（keep_latest）；社区"慎用裸 SQL 删中间检查点"。
- **bundle 拆分**：vite 官方 guide + #12209（过猛 manualChunks 把动态块拽回入口）——本仓现状与共识一致。
- **流式渲染**：token 合帧 30-50ms + React.memo 消息项 + 隔离在飞气泡（本仓已做后两样）。
