# 术语表

本仓高频黑话的一句话解释 + 权威出处。读 docs/代码撞到不懂的词先查这里；新词进了日常用语就回来登记一行。

| 术语 | 是什么 | 权威出处 |
|---|---|---|
| **金样** | 冻结的"这一页长什么样"合同（整页 payload 逐字节比对）。有意变更界面时同笔重导出并在提交里说清 diff——它是合同不是绊脚石 | `tests/unit/runtime_view_golden.json`，看守在 `test_settings_runtime.py` |
| **写点 / 单写点** | 一个设置**唯一**可改的界面入口；运行环境页对部分项只读展示并指向写点（"在「X」页签修改"） | `core/runtime_settings.py` 的 FieldSpec 注释 |
| **派生面** | 从单一注册表演算出来的视图（如运行环境 payload 全部由 FieldSpec 派生）。手工维护第二份清单 = 漂移，门禁会抓 | `core/runtime_settings.py`，`test_single_sources.py` |
| **门禁 fast 档** | 提交前的本地全家族：ruff / mypy 双档 / 依赖方向 / pytest / consistency / vitest / eslint / openapi 同步 / 响应模型 / parity | `scripts/gate.py --fast` |
| **四步流** | 设计先行的四步：①方案 → ②实现 → ③验证 → ④文档回写。**第④步不可跳**（完成记录倒序追加进 docs/开发流程.md） | docs/开发流程.md「全景图」 |
| **风险族（五族）** | 装配根、公开契约、进程生命周期、依赖面、门禁本体——动到这些的提交要格外自审 | docs/开发流程.md P12 节 |
| **编号三族** | `P1–P14`＝未完善清单项；`P{n}-{m}`＝审查快照条目；`R26/R28/R102-NN`＝评审决议。编号是身份，路径经索引解析 | docs/架构审计索引.md（生成物，别手改） |
| **UTC naive** | 库里所有时刻一律 UTC 且不带时区后缀（`CURRENT_TIMESTAMP`）。**展示前必须**经 `lib/quiet` 的换算出口，直接 `.slice()` 就是偏 8 小时那族 bug | `frontend/src/lib/quiet.ts`，`core/schema.sql` |
| **桶 / 作用域**（记忆） | `role_memory_item` 按 bucket 分：全局（用户事实，注入每个角色）/ `role_id`（角色专属） | `core/memory/__init__.py` 的 `memory_for_turn` |
| **数据根** | 可经环境变量隔离的数据目录（SQLite/Chroma/上传都在里面）。测试与装机靠它互不串 | `config.py`，`tests/conftest.py` |
| **dist 同笔** | `frontend/dist` 入库；动了前端源码必须**同一笔提交**里重建 dist（vite 会把 CRLF 源码的 `\r` 残进产物，见 gate 文档） | `.githooks/pre-commit` B 组 |
| **直推 main** | 单人开发口径（2026-10-30 起）：不开分支 PR，pre-commit + main CI 承接门禁 | docs/开发流程.md P12 口径更新段 |
| **页签名** | 左侧导航的六个签：对话 / 资料 / 角色卡 / 记忆 / 工具 / 设置。加页签=改注册表+懒加载项，别在别处手抄第二份清单 | `frontend/src/App.tsx` 的 `TABS` |
| **动作名** | 审计日志 `action` 列的枚举（`create_role` / `import_role_card` / `export_role_card`…）。改一个名就是劈历史——旧行不会跟着改 | `base/audit.py` 的 `AUDIT_ACTIONS`，看守在 `check_consistency` 的 audit action vocabulary |
| **收件箱** | 她主动开口后投递给你的那条记录（`agent_reachout` 行）。已读=不算未读但行还在；删=行消失但主动会话里的话不跟着删 | `api/routers/reachouts.py` |
| **事件簿** | 角色卡的只读时间线：主动开口/记下/更正/开始聊，三源合一按主人过滤 | `core/proactive/timeline.py`，界面 `TimelineDrawer` |
| **主动开口** | 她不经你提问来找你（五类触发源，排他 or 链）。全局总闸 + 角色级 opt-in 双层开关 | `docs/主动消息与记忆设计稿.md`，`features/reachout/` |
| **工作区** | 授权角色"碰电脑"的目录边界（文件事件触发与上传的根），由角色卡页托管 | `components/WorkspacePanel.tsx`，`roles/models.py` 的 `workspace_dir` |
