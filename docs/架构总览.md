## 1. 一句话定位与目标形态

**角色卡 = 人格 + 权限 + 工具 + 记忆的运行单元**；用户拥有"属于自己的角色"——它能接触
你的电脑（受控）、按事件主动找你、通过开放生态扩能，最终成为一个桌宠。这是区别于通用
对话助手（豆包等）的结构性差异点。

**目标形态：一套后端，双壳。**

| 壳 | 形态 | 能力边界 |
|---|---|---|
| **B/S** | 浏览器控制台（现状，已全功能） | 全功能，但无桌面驻留；主动开口只能"积压可查 + 轮询红点"（浏览器不给后台推送，如实降级；系统通知属 C/S 侧，接缝已做在壳那侧，见 §11.2） |
| **C/S** | 桌宠壳（里程碑 D，**Electron**；Tauri 骨架已撤下，理由见架构审计 §11.2） | 壳只负责三件事：**窗口**、**本地后端的进程生命周期**、**原生能力桥**（已落：托盘/置顶/透明窗/位置记忆/单实例/系统通知/开机自启/全局热键/原生目录对话框；形象层与语音（2026-09-28）——桌宠是**活的**：waifu 图面协议渲染自绘默认包（`scripts/tools/make_pet_sheet.py`，换装 = 换一张 8×9 的图 + 声明 5–8 行语义），"朗读消息"用**系统 TTS**（`speechSynthesis`，零依赖）由托盘开关控制；桥面 **21 个方法**（2026-09-28 数正；09-25 那次是 19，新增 `petVoiceEnabled` / `onPetVoice`）**只收会话 id、不收路径与命令**，且**没有通用 IPC 转发器**，见审计 §11.3）。界面**不在壳里再存一份** —— 窗口先落壳自带的本地着陆页，探活后跳后端托管的那份，两壳渲染同一个 dist |

单后端 = FastAPI + LangGraph 内核（`src/rolecard_agent/`）；前端 `frontend/`（React + TS）
构建产物 `dist` 由后端静态托管。两壳复用同一后端，桌面集成项仅在 C/S 生效。

### 1.1 「本地 / 云端」是两条互不相干的轴（问的人九成在问另一条）

| 轴 | 两档 | 在哪儿定 | 现在的真实状态 |
|---|---|---|---|
| **运行形态**：服务与数据在哪儿 | 纯本机（壳 + 随包后端，绑 127.0.0.1）↔ **公网部署**（服务器 + 浏览器访问） | `RUN_API_HOST` + `AUTH_MODE` + `Dockerfile` | 纯本机是**唯一真跑过**的那档；Docker 档 09-28 在 CI 的 Linux runner 上实跑过（build/护栏/鉴权/一次 API 往返，见 §4）；**挂到公网**那一步（TLS/域名）仍欠，见 §4「尚未关闭」|
| **模型后端**：这一次推理找谁算 | 本地 Ollama ↔ 云端 API（硅基流动等） | 设置→模型页（`model_provider` 一层一把 key + 模型行的增删）；**默认与失败回退链不在这儿** —— 它是「设置→服务」里对话优先级的第 1 位与其后（`api/routers/settings.py:197` 那句「编辑入口已统一到「服务」页签」就是这条的自证） | **两档都已实现**，而且本机现在对话默认走云端（库里 siliconflow 已配 key） |

两条轴可以任意组合：公网部署也可以全部用本地 Ollama，纯本机也可以全部用云端 API。
把"用云端模型"听成"部署到公网"（或反过来）是这条命名最常见的事故，所以写死在这里。

**"为什么没有登录页"也是这两条轴的混淆**。三个各自成立的事实叠在一起造成了这个观感：
① 现在跑的是 `AUTH_MODE=off`（`.env` 里没有 `AUTH_*` 项，单机零配置那一档）；
② 登录走 HTTP Basic 的**浏览器原生 401 弹框**，前端零代码，所以本来就不会长出"一个登录页"；
③ 认证判定里**本机来源永远放行**（`access.allowed` 第一条短路），所以即便开着 `on`，
从 127.0.0.1 进去也照样不需要凭据 —— 桌面壳与本机界面走的正是 127.0.0.1。
2026-09-25 实测（`AUTH_MODE=on` + 副本库起在本机 8124，不碰真库）：无凭据 `GET /api/sessions`
= **401 + `WWW-Authenticate: Basic`**、带使用者凭据 = 200、`/api/health` = 200（豁免）、
错 key = 401；非回环来源 + 使用者凭据打管理面 = **403**，同样来源换操作员凭据 = 放行。
**登录这条路径是通的**，它只是在这台机器上被故意关着。真正没做的是**数据不分**，见 §4.1。

## 2. 技术栈（当前）

**后端**（Python 3.13，`src/rolecard_agent/`）
- API：FastAPI + uvicorn；同步端点走线程池，对话 SSE 走专属线程池避免阻塞事件循环。
- 编排：LangGraph + LangChain（成对锁版本）；两节点循环（model↔tools）+ SQLite Checkpointer；`AGENT_MAX_STEPS` 上限防工具循环无界。
- 模型接入：`init_chat_model` 多后端同构（本地 Ollama + 任意 OpenAI 兼容云），回退链 ≤2，超时按客户端风格传参（本地后端 `base_url` 端点风格由 provider 决定）。
- 持久化：SQLite（WAL + FK + busy_timeout，`ThreadLocalConnection` 按线程分发 + 库代际防残留事务）；裸 sqlite3 + `.sql` schema，无 ORM，加列走幂等 `_migrate`。
- 向量检索：Chroma（一个作用域一个集合）+ 可插拔嵌入器（有 key 走 SiliconFlow bge-m3，无 key 走 hash 离线兜底）；索引身份 = 摄入任务 id（非文件名），删除连向量一起清。
- 文档摄取：pypdf + 标准库 zipfile/ElementTree（OOXML，禁 DOCTYPE 防 XXE/bomb）+ 可插拔 OCR（RapidOCR 在独立 venv 子进程，数据不出本机；云端 OCR 只能在「服务」页显式引用模型页的凭据行启用，绝不默认外发图片）。
- 配置：Pydantic v2 + 自研 `Settings.from_env`；`pyproject.toml` 单一依赖事实源，`requirements*.txt` 按范围拆分。
- 可观测：自研 Tracer 门面（JSON lines，键控脱敏 + 轮转）+ `audit_log` 表（只记路径/字节数/退出码，不记内容）+ `/api/health` 的 `error_count_recent`（P2-①：未捕获异常按签名聚到数据根 `errors/error.jsonl`，24h 滑窗计数）+ `/api/diagnostics/export`（P2-②：一键诊断包 zip，操作员门禁 + 审计 + 名单制脱敏）。langsmith/langfuse 预留字段解析保留、依赖已删。
- 质量工具：pytest（**全离线**，LLM 注入脚本替身）+ 覆盖率阈值 90% · ruff · mypy · **自研 check_consistency**（文档↔代码断言）· 真机冒烟 `smoke_check.py`。

**前端**（`frontend/`，React 18 + TypeScript + Tailwind v4）
- Vite 构建 + `tsc --noEmit` + ESLint（P8：eslint 10 flat + react-hooks 7，`exhaustive-deps` = error；`npm run build` 内联，快档另有独立步）；`dist` 有意入库（clone 后无 node 也能演示）。
- **自研 Hash 路由**（不用 react-router），6 页签全 `React.lazy` 分包。
- 深色模式（Tailwind v4 `@custom-variant dark`）+ 响应式（off-canvas 抽屉）；组件库 `components/ui/`。
- 测试：vitest（前端契约 + 组件行为，node 环境 mock fetch）。

**运行外部依赖**：Ollama（便携版）+ 本地多模态模型（一行多用：对话 + tools + 识图 + 思考）；
云端备用硅基流动；web_search 后端可选（Tavily key / ddgs / off）；反向图搜 `image_search`

## 3. 模块地图（后端模块 ↔ 功能，含到 C 的全部能力）

| 模块 | 职责 |
|---|---|
| `core/bootstrap.py` | **装配根**：建库/播种 → 服务实例化 → 知识库 + 注册表（由宿主注入的域接线）→ 图 → 热重建；`Runtime` 是可变量的**唯一持有者**，不起 HTTP 也能装配出可对话内核（C/S 复用，见 §7） |

| `api/main.py` | **HTTP 壳**：绑定地址护栏、注入宿主侧域接线、`build_runtime(...)`、路由/中间件（库代际 + 认证）/静态托管/ASGI 生命周期 |
| `api/deps.py` | AppContext（`Runtime` 的读穿视图，端点写法不变）、get_context/get_actor 依赖、错误映射 |
| `api/message_view.py` | 消息回放与轮次展开的 **DTO**（`serialize_message` / `expand_to_turns`）：从前混在 deps.py 的 120 行 —— 形状归形状、注入归注入，契约整支钉在 `tests/unit/test_serialize_message.py` |
| `api/diagnostics.py` | **P2 观测最小版的 api 面**：`install_unhandled_recorder`（泛型 500 收进统一 JSON 正文 + 签名记账 —— 从前 Starlette 对没注册 handler 的异常回裸文本，是 errors.py 收口后剩的第三个半）+ `GET /api/diagnostics/export`（一键诊断包：manifest + error.jsonl + 双日志副本，操作员门禁 + 审计 + 名单制脱敏，白名单外的 env 一律不进包） |

### 4.1 本地为底、登录换身份：目标形态与还剩什么

用户描述的目标形态：**不登录就用本机那份数据；登录则把服务器上属于我的那份拉下来；退出登录后
本机那份再装载回来。**

把它写成可判定的形式，最关键的一条取舍是：**这是"换身份"，不是"做同步"。**

- 本机与云端各是**一份完整数据集**，界面同一时刻只呈现活动身份那一份。
- 双向同步要求冲突合并规则（同一句改述在两台机器上各改一次算谁的），成本比这条计划的收益高一个
  量级 —— 先不做。也**不要顺手做成**"每次写都发一份到服务器"：那会在第一个断网时刻变成静默丢数据，
  而那正是本项目最贵的一类故障（它改的不是缓存，是"她记得什么"）。
- **上行**（什么时候把本机这份送上去、自动还是手动点一次）默认取最保守的那种：
  **只在界面上有一个"上传本机数据到账号"的显式按钮**，不自动上传。

**已落地**：认证与凭证分族、多租户第一批（按人分的表都按人了，`checkpoints`/`writes` 不加列、
靠线程归属校验）、双机同步六端点（inventory/plan/apply/export/pull/reconcile）+ 冲突裁决
（默认"新者胜"，三档可手选）、凭据不过手、逐条审计。前端是同步向导（方向切换 + 预检四格 +
裁决屏 + 登录后自动对账），读数卡只把"两端均有修改"的未决项端出来。

> **这一节的落地过程已从文档里删掉（2026-11-01）**：那些一次性探针、撞出的两个 bug、
> 逐条验收号是 git log 与 `tests/unit/test_sync*` 的职责 —— 文档里再抄一份只会与
> 真实实现**漂开**。要查"当时怎么做的"，看提交；要查**现在是什么**，看下面这段与 §1.1。

**这条计划还剩什么**：
- **同步第二批：健康档案与上传原件不传**（向导里那两类**不给复选框**是刻意的，不是漏了）。
  它要跨过的是本项目自己的那条线 —— 健康数据"上云留存"需要**单独征求同意**（云端推理能读

## 5. 关键架构决策与不变式（历轮沉淀，改动前必读）

这些是被机器校验或反复强调的**硬约束**，不是风格偏好：

1. **`core/` 领域中性**：内核不得出现任何域的专有名词 —— 域目录名（health 等）**以及各域
   自己声明的表名**（`check_core_no_domain_token` 机器校验，表名从 `domains/*/schema.sql`
   推导，新增域自动跟上；注释与 SQL 注释一并算）。只盯 "health" 一个字的旧版曾放过
   `core/ingestion.py` 里一句 `UPDATE medical_report …`（架构审计报告 P1-1，已改为由域服务
   `create_report(ingestion_task_id=…)` 在插入时一起写）。
   用户/租户是内核概念（已从 `domains/health` 上移到 `core`）。
2. **权限三重过滤、bind 阶段生效**：白名单在 `bind_tools` 阶段裁剪，未授权工具对模型
   **完全不可见**（不是调用时拦截）；插件停用递增 `tool_epoch`，跨版本恢复会话回答"能力已下线"
   而非抛异常。
3. **guard fail-closed**：输出侧硬 gate，异常路径也拦；`switch_role` 等不得交 LLM 自主调用（防自我授权）。
4. **System Prompt 不落 messages 历史**；全局安全规则代码固化 + 后置。多模态轮次（本轮模型可见
   历史含图片）另注入「图像接地」段，排在人设/记忆/范例之后、安全规则之前：**事实以图为准，
   角色只负责解读不捏造**——先如实看清图（含逐字转录文字），人设决定「怎么看怎么讲」而非「图里
   有什么」，不认识的东西走 `web_search` 查证、查不到就承认不知道（防人设/检索资料盖过真实像素）。
   含图会话切到不支持视觉的模型时，由 `core/agent/turn.py::model_error_detail` 翻成可操作提示（切回视觉模型 /
   新开不含图会话），不再吞成笼统的"模型调用失败"。
5. **AI 数据一律带【未经人工校验】标记**，标记拼进工具返回文本（不能让 LLM"记得说"）。
   常量在 `base/markers.py`（`UNVERIFIED_MARKER` 单条数据 / `AI_TEXT_MARKER` 整段模型产物），
   覆盖三处产出：域工具返回文本、AI 抽取写库的 provenance note、`compare_model_answers`
   的聚合结果（第一行）。
6. **审计只记路径/字节数/退出码，不记内容**；密钥只写不回读、永不出明文（运行环境视图掩码）。
7. **主动不绕过任何授权**：主动开口的动作与用户动作走同一套权限/审计/gate。
8. **per-role 隔离铁律**：主动开口的全部状态（触发配置/关系数值/回忆索引/校准/抑制）按
   `role_id` 隔离；记忆按角色取，回忆触发只查该角色自己的记忆；**唯一全局的是用户级护栏**
   （静默时段 / 未读堆积上限）。多角色 = 各自独立找用户聊，**角色间不互聊**。
9. **主动开口抑制与豁免**：三层抑制 = 间隔档（锚点是她**最后一次说话**，主动开口与在会话里
   回答都算，09-26）/ 静默时段（23:00–08:00）/ 未读堆积上限；
   `file_event` 触发**只豁免间隔档一次**，静默与未读是用户级护栏**不放松**。
10. **配置双源热切**：`Settings` 字段 + `from_env` 映射 + `RUNTIME_FIELDS` FieldSpec +
    settings runtime 视图组 + `.env.example` 契约五处必须同步（check_consistency 前缀元组含新
    env 前缀才放行）。运行环境在线改的字段保存即 `rebuild_runtime` 热生效。
    **例外：「用哪个 OCR / 嵌入 / 重排后端」不是配置项** —— 它只有「服务」页一个事实面
    （端点序 + 引用的模型页凭据）。这两族 env/在线开关曾存在过，但生产上从不被读
    （`seed_once` 恒播种一条启用的内置行 ⇒ 工厂里的 env 分支不可达），"改了没生效"的开关
    比没有开关更糟，已随架构审计报告 P1-5 收口删除。
11. **改数据契约走变更记录**：加列走幂等 `_migrate`；公开签名不破坏。**搬层/重建表允许**
    （2026-09-21 模型配置拆成 `model_provider` + `model_backend` 两层就是这一条），但要同时满足
    三件事：① 读侧形状不变（服务层用 JOIN/派生补齐被删的列，内核与消费方一行不改）；
    ② **搬完配置不许变小**（模型行、凭据、默认与回退顺序一个都不能少 —— 变多是可接受的
    宽松化，变少是丢用户的东西）；③ 拿本机演示库的**副本**跑一遍迁移并逐行对照，结果写进
    设计稿（不是"新库测过了"就算完）。旧列一律在迁移里删掉而不是"留着但不用"：一个没人读
    的列就是下一个假接缝。表/列名不改是默认姿势，不是禁令 —— 上面三条才是。
12. **模型能力标在后端、换模型对所有角色统一生效**：`model_backend` 带 `supports_vision`
    （能否收图）与 `supports_tools`（工具调用是否可用）。`call_model` 每轮按
    **当前模型**的能力自适应——`supports_tools=false` 就不绑工具（这条是**后端硬生效**）。

    已落地，2026-09-20）：只有"该行声明 false"**且**"Ollama `/api/show` 的 capabilities
    实测不含 vision"同时成立才拒这一轮，探测问不到 / 云端探不了 / 声明 true 一律放行，
    供应商 400 的翻译路径作为兜底保留。**仍然不** disabled 发图按钮 —— 判定只在一处（后端），
    界面复制一份就是第二个事实面。口径是用户选的"只拦确定的否"（误杀一个能看图的模型，
    比多花一次 400 往返严重）。文档以前写"决定发图按钮"是超前描述，已按现状收回。
    这样"切到某个云端 VLM"
    对任意角色都能用，不必为绕模型缺陷去建特殊角色（用户 2026-09-19：能力是模型的属性）。
13. **轮次事件名是跨语言线协议**：内核侧唯一声明处是 `core/agent/turn.py` 的 `EVENT_TYPES`
    （每个事件类自带 `sse_type`，帧化直接读它，不存在第二份字符串清单），前端侧是
    `api/sse.ts` 的 `ChatEvent` 联合。两者由 `tests/unit/test_frontend_contract.py` 做双向差分
    —— 改一边不会让另一边编译失败，症状只是"那一类东西从此不显示"。
14. **一轮对话的编排不属于 HTTP 层**：跑图、流式审核、文本对账、失败翻译全在 `core/agent/turn.py`，
    投送方式（SSE / 桌宠原生事件 / 脚本直取）是宿主的事。
15. **记忆有上界，且退役不物理删**：每桶 active 条数有上限（超出即退役最弱的）、注入按字符预算
    **整条**截断（半条事实会被当完整事实用）；自动退役只写 `invalidated_at` / `superseded_by`
    （可撤销、可查、整理错了能回滚），**只有用户明确删除才物理删**。命中计数只涨在真进了
    prompt 的那几条上——它是退役排序里"频次"那一半的唯一来源，所以必须长在注入路径上。
16. **端点必须表态，默认最严**：`api/access.py` 那张清单是"哪些端点能影响主机"的唯一答案；
    没登记的路由自动按 operator 处理，想让某条**更宽松**必须写一行。配的用例枚举运行时路由，
    清单里出现死条目即红（降级悄悄失效比没降级更糟）。
17. **用哪台后端：会话 > 角色 > 全局优先级，而全局那份始终是兜底的那条链**。角色卡上的
    `model_name` 是"这个角色归谁接"，它赢过「服务」页那串顺序里的第一档；留空就是完全跟着
    全局走（解析器连名字都不点，由运行时按 `model_default` 定）。**但换 primary 不换池子**：
    角色挑了靠后那台时，降级链仍是 `[全局默认, *回退档]` 去掉它自己 —— 操作员排第一那台是
    最被信任的备胎，把它从链上抹掉等于"角色选了个冷门后端，连兜底都没了"（这条 09-25 之前
    就是那样错的）。用量账记的是**实际接话那台**（`Settings.backend_name`，声明的已被删掉
    就落回默认），不是角色卡上写的那台：记成 NULL 会让"没设置"那些轮次在按后端分组的页上
    凭空消失，而角色级选择用得越多，那个洞越像 bug。
    **"选哪台"与"花谁的 key"是同一答案的两半**（09-27 收口）：同一条链在每个身份眼里各是
    一份快照（`Runtime.effective_for`，节点侧经 `core/agent/nodes.py` 的 `turn_settings` 取），
    所以校验某个后端名合不合法时必须问**这一轮的主人** —— 按实例主人问会放行一个
    "存得下、跑不动"的名字，下一轮只能降级到别人的模型（= 花别人的 key）。
18. **范例教句式，不教事实**（09-27 定，`Q8`）：`RoleExemplar` 里写进一条真实数值 / 日期 /
    人名，模型就有概率在**别的问句**上把那个数当成你的事实复读出来 —— 那是 A3 那把引用尺子里的
    `answer_absent_value`。默认写法是"这一句该有什么结构、哪里要停"，数值让模型自己去档案里取。
    唯一的例外要写清，因为出厂那张档案管理员卡正落在例外里：当一条范例的**存在理由**就是教一个
    带格式的读数（结尾那句【未经人工校验】标记），数值可以给，但必须是**演示数据里真有的那一个**
    —— 不许编（编的数会被当可引用真值），也不许是评测题的答案（`check_consistency.py`
    的「exemplar leaks eval answers」那条机器检查：一旦是答案，模型学会的是背范例而不是调工具）。
    界面上这句写在角色页范例那一栏下面，因为它要在**写的那一刻**被读到，不是写在文档里。
19. **四个事实面各有一个词，界面上不许互相借字**（09-30 拍，`R28-45`）：这条不是文风偏好而是
    可导航性 —— 一个词指两层，人就会按字面去找那个入口而找不到（关于页那句"改默认后端请去
    「模型」页"就是这么个改不到的入口）。定案：
    **厂商** = `model_provider`（只装凭据）· **模型** = `model_backend` 那一行（后端名字在界面上
    一律叫"模型"，字段叫"模型名"）· **服务** = `service_endpoint` 那条**优先级**（「默认」与失败
    回退链的家在这一层，正文写"对话优先级/嵌入优先级"，「服务」继续当页面名）·
    **本机程序** = 那个 FastAPI 进程本身（它没有模型，所以"连不上后端"这种话以前把三层压成一句；
    它的地址叫"程序地址"，随包那份叫"本机程序"而不是"随包后端"）。
    守住它的是 `check_consistency.py` 的 **`ui vocabulary`**：扫 `frontend/dist` 产物（压缩后没注释
    ⇒ 落在那儿的字必然给人看）+ `src/**/*.py` 的**字符串常量**（docstring 与注释刻意不算 ——
    那里「后端」仍然精确指 `ModelBackend` 那一行，扫它是自造噪声），红名单是那九个把两层压成
    一个词的说法；裸「后端」只数不拦、数量上屏。判据细节与否证方式见台账 `R28-45`
    （经 [`架构审计索引`](架构审计索引.md) 解析）。
20. **依赖方向只有向下，`base/` 是最底层**（2026-10-04 收口，`pyproject.toml` 的
    `[tool.importlinter]` 两条契约机器看着；跑法 `scripts/check_import_layers.py`，已进门禁静态组）：

    ```
    api → domains → (features) → core → { roles | rag } → base → storage → config
    ```

    `base/` 收的是"谁都要问一遍"的零业务知识原语（见 §3 那一行）。它**只许** import 标准库 /
    第三方 / `config` / `storage` / `base` 自己，反向 import 任何上层即红
    （便宜的 AST 尺子在 `tests/unit/test_import_floor.py`，单独跑 pytest 也拦得住）。
    `roles` 与 `rag` 在同一层且**互不依赖**；`(features)` 是产品功能包（桌宠形象包已迁入），
    方向**已用探针双向实测**：features import core 放行、core import features 红 —— 内核要
    知道某个功能只能走注册表（`Runtime.register_background` 只认 start/stop）。`domains`
    现在还在 `core` 之上，因为域的工具工厂拼的是内核件（`domains → core` 一堆依赖），
    域机制自描述化之后**这一格仍未翻**：翻它的前提是先把那些依赖挪走，否则契约当场红。

    为什么值得单独钉一条：这几件原语从前住在 `core`，于是 `rag`/`roles` 想借一把就得
    **反向 import 内核**，`core ↔ rag`、`core ↔ roles` 两条双向边就是这么长出来的。它们当时
    靠函数内的延迟 import 压着不炸环，**看起来一切正常**，代价是"顺手把某个 import 提到
    模块顶层"这种无害重构会当场引爆循环导入，而没有任何尺子会提前出声。原语下沉之后
    "反向"在结构上就构不出来 —— 这是本仓删守卫而不是加守卫的那笔（新增的是两条契约与
    一个包装脚本，没有新增人工约定）。

## 6. 安全模型总纲（贯穿所有里程碑）

- **fail-closed 贯穿**：认证、guard、工具白名单、路径边界、审批默认（run_command 默认手动批准）。
- **端点按"能影响什么"分级**（`api/access.py`）：public / user / **operator**，**默认最严**——没在
  清单里表态的端点自动算操作员面。判定顺序是三条短路，2026-09-25 逐条量过（真值表见架构审计「「本地 / 云端」同时指两件事」）：
  **本机来源永远放行** → 已声明 `operator:` 凭据时只认操作员族 → 一条都没声明则整套分族休眠
  （否则"AUTH_MODE=on + 只有一条 `alice:pw`"的老配置会把主人锁在自己的设置页外）。
  第二条正是"我从 127.0.0.1 测不出分族"的原因，别把它当失效。`off` 档不启用分级（语义就是本机
  单人使用，且非回环绑定已被启动护栏拒绝）。用户自己日常用的（对话/会话/自己的数据/角色卡/
  记忆）都在 user，**不需要登录**。**默认最严**这半句是专门用来堵"`AUTH_EXEMPT_PATHS` 配宽了一点
  就让管理端点免凭据可达"的 —— 漏写一行是收紧而不是放开。
- **路径边界**：任务目录外读写一律拒绝（`_resolve_within`）；run_command cwd 必落任务目录内。
- **联网边界**：联网总闸 + 域名白名单 + web_fetch 逐跳 SSRF 校验；未配 key 不外发。
  `image_search`（SauceNAO 反向图搜）同受联网总闸管，未配 `SAUCENAO_API_KEY` 时返回可读提示、
  **绝不静默上传**用户图片（与云端 OCR 同一"图片外发需显式配置"义务）。
- **审批共用确认 UI**：命令审批（B/S 确认卡，C/S 系统弹窗）；批准一次跑 N 遍被结构禁止（回放）。
  **批准还要持有凭据**：每条待批由读侧下发一次性 `decide_token`（30 分钟过期、决定后清空），
  `decide` 缺 / 错 / 过期 = 403。它不是登录（单机形态本来就不登录），而是"这一条你确实看到过"
  —— 于是"猜自增 id 就批准"和浏览器里的跨源盲 POST 都不成立（读不到响应就拿不到令牌）。
- **不做 Agent 自扩权，但允许 operator 主动接入**：红线是"运行中的 LLM Agent 自己启用/安装
  能力"——绝不允许（启停/接入从不暴露为 LLM 工具，见 `domains/registry.py`）。**用户在设置里
  主动接入 MCP server 是合法的 operator 动作**：`/api/mcp/servers` CRUD（仅 http 传输；URL 由
  operator 主动填故本机/内网/公网均可——"仅公网"的 SSRF 边界只用于模型给的 URL，如 web_fetch；
  headers 只写不回读掩码；全程审计；启停热重载；**添加即自动测、连不上仍保存但标红**）。
  env `MCP_SERVERS` 与运行时 `mcp_server` 表并存合并（表覆盖同 id）。**MCP 是可选扩展层**
  （与 OCR/RAG 同层）：源码/B-S 形态需 `pip install -r requirements/requirements-mcp.txt`，未装时接入/测试给可操作提示。
  **随包后端今天把它俩都打进包里了（2026-09-29，`R28-34`）**：此前 spec 收的是"构建机恰好装过"的那些，
  而 `langchain_mcp_adapters` 在 .venv 里根本没装 ⇒ 包里 0 个模块 ⇒ **桌宠包里的 MCP 永远 fail-open**
  （那格照常摆着、交通灯照常画，工具永远加载不出来，只有日志一句 warning；而且对包内的人
  "pip install" 是一句不可执行的建议）。代价实测 1.87 MB（约占整包体积的 1%；"整包多大"这里
  故意不写死，理由见上面里程碑 D 那一段，pip dry-run 确认
  除这两个包外无任何其他版本被推动）。现在有两道闸：spec 缺包**直接拒绝出产物**，
  以及 `scripts/check_bundle_parity.py`（full 档）拿 AST 扫出的 src 第三方 import 逐个问已打好的包。
  插件同理：启停是 operator 动作，不做 LLM 自助安装。
- **数据保护**：LangSmith/云端可观测默认关闭；健康数据不外发除非显式配置。
- **单机形态的来源标识（`R102-45` 根因已修，本条现为纵深防御口径）**：
  默认 `off` 档的等式是"能连上 127.0.0.1 的 = 本人"，但**浏览器里的网页同样能连上**——
  DNS rebinding（恶意域名 A 记录指到 127.0.0.1）与跨源盲 POST 的 TCP 对端也是 127.0.0.1，
  实测可读全库数据、从待批列表原文拿到 `decide_token`、替用户批准并真实执行命令
  （2026-10-02 复审主控全链复跑，见台账 `R102-45`，经 [`架构审计索引`](架构审计索引.md) 解析）。
  **修法（批 1 已落地）**：来源标识中间件在认证**之前**再验一层"来源是谁"——off 档要求 Host
  命中回环名（`127.0.0.1` / `localhost` / `[::1]`），全档要求带 `Origin` 的请求同源
  （`api/auth.origin_guard_violation`）；`LOCAL_ORIGIN_ENFORCE=0` 是一键回旧行为的开关。
  要更强的边界（多凭据 / 公网）仍用 `AUTH_MODE=on` + `AUTH_CREDENTIALS` 里的
  `operator:用户名:密码` 条目 —— 代价是控制台访问过一次 Basic 弹框。**边界要说清**：
  `auto`/`on` 档下 loopback 匿名仍可达 user 面（"本机来源永远放行"那一条没变）——那是刻意的，
  主人坐在键盘前不该被自己的机器挡住；真正的边界在 operator 面与下面的数据出口清单上。
  Docker/公网形态不受本条影响——那边的 `AUTH_MODE=on` 是 deploy env parity 尺子的强制项。
- **数据出口也有边界（`R102-58`）**：上行同步（`/api/sync/*`）属使用者档（它是"搬自己的数据"
  这个日常动作），于是从前**任意公网地址都收** —— 多凭据部署里，持使用者凭据者可把该身份的记忆
  与会话全量推到自己控制的服务器。现在目的地址要过 `SYNC_ALLOWED_HOSTS`：默认空 = 只允许本机
  回环；新增一台由 operator 在「设置 → 运行环境」确认（也可写 `.env`），保存即生效。
  `AUTH_MODE=off` 时不入档，单机形态逐字不变（判据在 `api/access.outbound_target_allowed`，
  三个出站执行器入口各挂一次）。
- **凭据与数据同住一个存储面（`R102-57` 的正式取舍，不是待修项）**：模型 api_key 与对话原文
  一起明文住在 `app.db` 里（API 响应面纪律良好：key 只写不回读、审计 0 命中）。**不做应用层
  加密** —— DPAPI 那类方案把库绑到一台机器上，备份还原跨机器就要重录全部 key，代价大于收益；
  于是取舍写明在这：**`app.db` 文件本身 = 凭据**，它（连同 `-wal` 与导出的备份 zip）要与凭据
  同等级保护，备份目录的 ACL 收紧到使用它的那个账号。

## 7. 质量与门禁纪律

- **历史审计台账已删除**（2026-11-01 用户拍板："以前归档的也准备删了"）。判据与结论不留档：
  留在活文档里的判据（本文 §5 不变式、`需求与验收标准.md` 的验收口径）才是要留的；
  过程性的台账与快照只留一份"结论已并入活文档"的记录。
  **新发现开下一轮时另起一份 `docs/架构审计（<日期> 轮）.md`，收口后同样删掉**。
  拦着不搬的那条理由已经作废：从前搬一份进 `archive/` 会让 `audit citations` 从 27 条黄跳到
  124 条黄（09-25 实测），因为**引用把"存放地"当成了"身份"**。现在解法是
  [`架构审计索引.md`](架构审计索引.md)：`§x.y` / `P{n}-{m}` 这些**编号才是身份**，
  索引给每条编号一行"说的是什么 + 现在住在哪个文件"，由 `scripts/tools/build_audit_index.py` 生成、
  由 `audit index in sync` 那条断言比字节钉住（搬完档只需重跑一次生成器，不动那 444 处引用）。
- **读数以 `scripts/baseline.py` 为准**：它产出 `build/baseline.json`（路由表、Settings 字段数、
  schema 漂移、两个数据根的会话集合、安装包与 dist 是否同版、引用计数）。写它的原因很实在：
  审计文档里"约 15 处 `DEFAULT_USER_ID`"与实测 22 处差 7 处，差的不是事实而是**谁数的**。
- **`check_consistency.py` 的 `audit citations`**：验证代码里每一处 `§x.y`/`P0-x` 真的指得到
  东西。判据（10-01 改过一次）：查无此号才红；**在不在 `archive/` 不再决定颜色** ——
  一个编号只要能在某份文档里解析到、且索引里有它那一行，它就是可达的。归档区里剩下会黄的只有一种：
  **索引里没有、只在归档文档里出现**的号（那说明它是被搬档甩下的旧规划，不是台账里的决定）。
- 分层门禁（`scripts/gate.py`）：**平时迭代 `--fast`（ruff + mypy + 单测 + 一致性）**；
  仅提交/发布前跑**全量**（+ 覆盖率门槛 + 前端 test/build + 真机冒烟）。
  各档实测耗时与分层用法见 [`开发流程.md`](开发流程.md) 门禁一节 —— 慢是会变的数，本文不抄。
  更快的反馈是只跑相关测试文件。
- 提交前：Conventional Commits（`feat`/`fix`/`docs`/`test`/`refactor`/`chore`）；不提交 `.env`、
  真实数据、任何密钥；演示数据全部虚构。
- 文档纪律：见 [`开发流程.md`](开发流程.md)——每个能力先在设计文档留痕再实现，实现后回写覆盖矩阵。
