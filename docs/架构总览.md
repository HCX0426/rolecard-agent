## 1. 一句话定位与目标形态

**角色卡 = 人格 + 权限 + 工具 + 记忆的运行单元**；用户拥有"属于自己的角色"——它能接触
你的电脑（受控）、按事件主动找你、通过开放生态扩能，最终成为一个桌宠。这是区别于通用
对话助手（豆包等）的结构性差异点。

**目标形态：一套后端，双壳。**

| 壳 | 形态 | 能力边界 |
|---|---|---|
| **B/S** | 浏览器控制台（现状，已全功能） | 全功能，但无桌面驻留；主动开口只能"积压可查 + 轮询红点"（浏览器不给后台推送，如实降级；系统通知属 C/S 侧，接缝已做在壳那侧，见 §11.2） |
| **C/S** | 桌宠壳（里程碑 D，**Electron**；Tauri 骨架已撤下，理由见架构审计 §11.2） | 壳只负责三件事：**窗口**、**本地后端的进程生命周期**、**原生能力桥**（已落：托盘/置顶/透明窗/位置记忆/单实例/系统通知/开机自启/全局热键/原生目录对话框；桥面九个方法**只收会话 id、不收路径与命令**，且**没有通用 IPC 转发器**，见审计 §11.3）。界面**不在壳里再存一份** —— 窗口先落壳自带的本地着陆页，探活后跳后端托管的那份，两壳渲染同一个 dist |

单后端 = FastAPI + LangGraph 内核（`src/rolecard_agent/`）；前端 `frontend/`（React + TS）
构建产物 `dist` 由后端静态托管。两壳复用同一后端，桌面集成项仅在 C/S 生效。

## 2. 技术栈（当前）

**后端**（Python 3.13，`src/rolecard_agent/`）
- API：FastAPI + uvicorn；同步端点走线程池，对话 SSE 走专属线程池避免阻塞事件循环。
- 编排：LangGraph + LangChain（成对锁版本）；两节点循环（model↔tools）+ SQLite Checkpointer；`AGENT_MAX_STEPS` 上限防工具循环无界。
- 模型接入：`init_chat_model` 多后端同构（本地 Ollama + 任意 OpenAI 兼容云），回退链 ≤2，超时按客户端风格传参（本地后端 `base_url` 端点风格由 provider 决定）。
- 持久化：SQLite（WAL + FK + busy_timeout，`ThreadLocalConnection` 按线程分发 + 库代际防残留事务）；裸 sqlite3 + `.sql` schema，无 ORM，加列走幂等 `_migrate`。
- 向量检索：Chroma（一个作用域一个集合）+ 可插拔嵌入器（有 key 走 SiliconFlow bge-m3，无 key 走 hash 离线兜底）；索引身份 = 摄入任务 id（非文件名），删除连向量一起清。
- 文档摄取：pypdf + 标准库 zipfile/ElementTree（OOXML，禁 DOCTYPE 防 XXE/bomb）+ 可插拔 OCR（Paddle 在独立 venv 子进程，数据不出本机；云端 OCR 只能在「服务」页显式引用模型页的凭据行启用，绝不默认外发图片）。
- 配置：Pydantic v2 + 自研 `Settings.from_env`；`pyproject.toml` 单一依赖事实源，`requirements*.txt` 按范围拆分。
- 可观测：自研 Tracer 门面（JSON lines，键控脱敏 + 轮转）+ `audit_log` 表（只记路径/字节数/退出码，不记内容）。langsmith/langfuse 预留字段解析保留、依赖已删。
- 质量工具：pytest（**全离线**，LLM 注入脚本替身）+ 覆盖率阈值 85% · ruff · mypy · **自研 check_consistency**（文档↔代码断言）· 真机冒烟 `smoke_check.py`。

**前端**（`frontend/`，React 18 + TypeScript + Tailwind v4）
- Vite 构建 + `tsc --noEmit`；`dist` 有意入库（clone 后无 node 也能演示）。
- **自研 Hash 路由**（不用 react-router），6 页签全 `React.lazy` 分包。
- 深色模式（Tailwind v4 `@custom-variant dark`）+ 响应式（off-canvas 抽屉）；组件库 `components/ui/`。
- 测试：vitest（前端契约 + 组件行为，node 环境 mock fetch）。

**运行外部依赖**：Ollama（便携版）+ 本地多模态模型（一行多用：对话 + tools + 识图 + 思考）；
云端备用硅基流动；web_search 后端可选（Tavily key / ddgs / off）；反向图搜 `image_search`
可选（SauceNAO key，识别动漫/插画角色来源，未配 key 则该工具返回可读的未配置提示、不外发）。

## 3. 模块地图（后端模块 ↔ 功能，含到 C 的全部能力）

| 模块 | 职责 |
|---|---|
| `core/bootstrap.py` | **装配根**：建库/播种 → 服务实例化 → 知识库 + 注册表（由宿主注入的域接线）→ 图 → 热重建；`Runtime` 是可变量的**唯一持有者**，不起 HTTP 也能装配出可对话内核（C/S 复用，见 §7） |
| `core/identity.py` | v1 单用户演示身份的常量与播种（`DEFAULT_USER_ID` / `seed_demo_identity`）—— 内核概念，不归任何域、也不在 api 层重复定义 |
| `api/main.py` | **HTTP 壳**：绑定地址护栏、注入宿主侧域接线、`build_runtime(...)`、路由/中间件（库代际 + 认证）/静态托管/ASGI 生命周期 |
| `api/deps.py` | AppContext（`Runtime` 的读穿视图，端点写法不变）、get_context/get_actor 依赖、错误映射 |
| `api/auth.py` | Basic + X-API-Key 双凭证；三档 `AUTH_MODE`；`client_ip` 只认 TCP 对端（可信反代 CIDR）；fail-closed |
| `api/routers/` | 端点组：roles / sessions / records / domains / console / settings / services / **workspace** / **reachouts** / **approvals** / mcp / **local_service**（本地推理服务状态与显存释放，仅回环）/ **shell_release**（桌面壳安装包的托管下载：只报"有没有产物"，文件名由服务端列目录得到） |
| `api/chat.py` | **SSE 投送层**：`core/turn.py` 的事件帧成 Server-Sent Event（事件名取自事件类自带的 `sse_type`，无第二份清单）+ 专属有界线程池桥。`/api/prompt/enhance` 在 sessions 路由 |
| `core/turn.py` | **一轮对话的编排（宿主无关）**：跑图 → `Iterator[TurnEvent]`（Start/Thinking/Token/ToolCall/ToolResult/MessageReplace/ContextTrimmed/Error/End）。流式 fail-closed 审核（`StreamingGuard` + `WINDOW` 回扣）、已提交文本与已投送文本的对账、失败翻译成人话——**全在这里，不在 HTTP 层**。桌宠壳直接消费它，不必吃 SSE |
| `core/graph.py` + `nodes.py` | 内核图、prompt 现拼、输出审核、工具三分类失败、历史裁剪（`CONTEXT_MAX_CHARS`，截断点不落 ToolMessage）、思考模型注入 |
| `core/guard.py` | 输出侧硬 gate（fail-closed，异常也拦）——安全第二层 |
| `core/text.py` | `text_of()`：消息 → 纯文本的**全项目唯一实现**（分块列表按空格连接，绝不产出 Python repr）。唯一性由 check_consistency 的 `single text extractor` 断言机器校验（P1-8）。配套 `core/markers.py`：【未经人工校验】/【AI 多模型比对·未经人工校验】标记常量（§5 第 5 条） |
| `core/plugins.py` + `tools/registry.py` | 插件启停（`tool_epoch`）、工具注册与两阶段过滤（bind_tools 阶段生效）、幂等重试开关 |
| `core/ingestion.py` | intake 台账（file_hash 幂等、状态机 pending→parsed→indexed/failed）、上传流式哈希 |
| `core/model_settings.py` / `runtime_settings.py` | 模型后端 CRUD（key 只写不回读）+ 热重建；运行环境在线覆盖（校验整体拒绝、空值回落 env） |
| `core/workspace.py` | **A** 任务目录解析与热切、受路径边界约束的只读树浏览（`resolve_task_dir`） |
| `core/reachout.py` | **B/C** 主动开口调度器：两级授权 + 三层抑制 + 关系驱动四类触发源（file_event/affection/time_pattern/recall/timer，first-hit-wins）+ 收件箱。**开口不只进收件箱**：宿主注入的 `deliver` 会把同一句落进"该角色的主动会话"（`proactive_thread_id(role_id)`，确定性 id），于是用户点得进历史、也能回话，角色也记得自己主动说过什么 |
| `core/file_watch.py` | **C** 任务目录轮询 + 哈希差量：快照/基线（`kernel_meta` 单行 JSON）/diff/过期 |
| `core/proactive_state.py` / `core/memory.py` | 好感度增长·衰减模型；per-role 记忆读写（与全局 `memory:facts` 隔离）。**"这一轮该注入什么记忆"只有一份实现**：`memory_for_turn(角色专属 → 无则回退全局，总开关关掉则空)`，对话与主动开口都走它（以前对话侧只取全局，角色专属内容聊天时进不了 prompt） |
| `core/approvals.py` + `tools/run.py` | **C** `ApprovalService` 状态机（pending→approved→done，拒绝终态；批准一次跑 N 遍被结构禁止）+ run_command（Popen + 进程树终止、cwd 必落任务目录、64KB 截断、机密不落审计） |
| `core/tools/mcp.py` | **C** MCP 通道（config/env 驱动，界面有意不做——见 §6） |
| `core/parent_watch.py` | **父进程看门狗**：桌面壳注入 `ROLECARD_PARENT_PID`，父没了后端就自尽（不留孤儿占端口与显存）。做在后端而非壳里，是为了让这条保证与壳用什么语言无关；判不准时一律当"活着"（宁缺毋滥，绝不误杀） |
| `core/domain_data.py` / `consensus.py` / `probes.py` | 通用领域数据服务（路由不直写 SQL）；多模型比对工具；模型能力探针原语 |
| `core/tools/` | web（联网总闸 + 域名白名单 + SSRF 逐跳边界 + `image_search` 反向图搜）、files（工作区读写，全进审计）、errors（用户安全错误透传）、builtin |
| `roles/` | 角色卡模型/服务/双种子（BUILTIN 出厂 + DOMAIN 降级自定义）；列含 `reachout_enabled`/`recall_enabled`/`time_pattern_enabled`/`file_watch_enabled` 等主动开口开关 |
| `domains/health/` | 示例领域：schema、服务、工具、三层校验抽取（schema→确定性→原文锚定 + 第二模型交叉验证） |
| `rag/` | parser（txt/pdf/OOXML）、ocr（可插拔后端 + vision 探测）、retriever（嵌入/重排/知识库/search_knowledge 工具，作用域由内核注入） |
| `storage/db.py` | connect（WAL/FK/busy_timeout）、ThreadLocalConnection（库代际回滚）、`_migrate` 幂等加列、bootstrap |
| `config.py` | 全部环境变量 → Settings；`.env.example` 同步受 check_consistency 校验 |
| `shell/`（Electron，非 Python 包） | 桌面壳：`main/backend.ts` 后端进程生命周期（探活/spawn/回收，**只动自己 spawn 的那个**）、`main/windows.ts` 两扇窗的形态、`main/state.ts` 窗口位置记忆（还原前夹回当前工作区）、`main/tray.ts` 托盘与"关窗=收起、托盘才是退出入口"、`preload/bridge.ts` **页面能拿到的一切原生能力**（每多暴露一个方法就是给后端那个源多开一条碰到桌面的口子）、`web/index.html` 本地着陆页 |

## 5. 关键架构决策与不变式（历轮沉淀，改动前必读）

这些是被机器校验或反复强调的**硬约束**，不是风格偏好：

1. **`core/` 领域中性**：内核不得出现任何域的专有名词 —— 域目录名（health 等）**以及各域
   自己声明的表名**（`check_core_no_domain_token` 机器校验，表名从 `domains/*/schema.sql`
   推导，新增域自动跟上；注释与 SQL 注释一并算）。只盯 "health" 一个字的旧版曾放过
   `core/ingestion.py` 里一句 `UPDATE medical_report …`（架构审计报告 P1-1，已改为由域服务
   `create_report(ingestion_task_id=…)` 在插入时一起写）。
   用户/租户是内核概念（已从 `domains/health` 上移到 `core`）。
2. **权限三重过滤、bind 阶段生效**：白名单在 `bind_tools` 阶段裁剪，未授权工具对模型
   **完全不可见**（不是调用时拦截）；插件停用递增 `tool_epoch`，跨版本恢复会话回答"能力已下线"
   而非抛异常。
3. **guard fail-closed**：输出侧硬 gate，异常路径也拦；`switch_role` 等不得交 LLM 自主调用（防自我授权）。
4. **System Prompt 不落 messages 历史**；全局安全规则代码固化 + 后置。多模态轮次（本轮模型可见
   历史含图片）另注入「图像接地」段，排在人设/记忆/范例之后、安全规则之前：**事实以图为准，
   角色只负责解读不捏造**——先如实看清图（含逐字转录文字），人设决定「怎么看怎么讲」而非「图里
   有什么」，不认识的东西走 `web_search` 查证、查不到就承认不知道（防人设/检索资料盖过真实像素）。
   含图会话切到不支持视觉的模型时，由 `core/turn.py::model_error_detail` 翻成可操作提示（切回视觉模型 /
   新开不含图会话），不再吞成笼统的"模型调用失败"。
5. **AI 数据一律带【未经人工校验】标记**，标记拼进工具返回文本（不能让 LLM"记得说"）。
   常量在 `core/markers.py`（`UNVERIFIED_MARKER` 单条数据 / `AI_TEXT_MARKER` 整段模型产物），
   覆盖三处产出：域工具返回文本、AI 抽取写库的 provenance note、`compare_model_answers`
   的聚合结果（第一行）。
6. **审计只记路径/字节数/退出码，不记内容**；密钥只写不回读、永不出明文（运行环境视图掩码）。
7. **主动不绕过任何授权**：主动开口的动作与用户动作走同一套权限/审计/gate。
8. **per-role 隔离铁律**：主动开口的全部状态（触发配置/关系数值/回忆索引/校准/抑制）按
   `role_id` 隔离；记忆按角色取，回忆触发只查该角色自己的记忆；**唯一全局的是用户级护栏**
   （静默时段 / 未读堆积上限）。多角色 = 各自独立找用户聊，**角色间不互聊**。
9. **主动开口抑制与豁免**：三层抑制 = 间隔档 / 静默时段（23:00–08:00）/ 未读堆积上限；
   `file_event` 触发**只豁免间隔档一次**，静默与未读是用户级护栏**不放松**。
10. **配置双源热切**：`Settings` 字段 + `from_env` 映射 + `RUNTIME_FIELDS` FieldSpec +
    settings runtime 视图组 + `.env.example` 契约五处必须同步（check_consistency 前缀元组含新
    env 前缀才放行）。运行环境在线改的字段保存即 `rebuild_runtime` 热生效。
    **例外：「用哪个 OCR / 嵌入 / 重排后端」不是配置项** —— 它只有「服务」页一个事实面
    （端点序 + 引用的模型页凭据）。这两族 env/在线开关曾存在过，但生产上从不被读
    （`seed_once` 恒播种一条启用的内置行 ⇒ 工厂里的 env 分支不可达），"改了没生效"的开关
    比没有开关更糟，已随架构审计报告 P1-5 收口删除。
11. **改数据契约走变更记录**：表/列名不改，加列走幂等 `_migrate`；公开签名不破坏。
12. **模型能力标在后端、换模型对所有角色统一生效**：`model_backend` 带 `supports_vision`
    （能否收图）与 `supports_tools`（工具调用是否可用）。`call_model` 每轮按
    **当前模型**的能力自适应——`supports_tools=false` 就不绑工具（这条是**后端硬生效**）。
    ⚠️→✅ `supports_vision` 现在消费在两处：渲染徽标，以及**调用前拦截的一半证据**（P1-2
    已落地，2026-09-20）：只有"该行声明 false"**且**"Ollama `/api/show` 的 capabilities
    实测不含 vision"同时成立才拒这一轮，探测问不到 / 云端探不了 / 声明 true 一律放行，
    供应商 400 的翻译路径作为兜底保留。**仍然不** disabled 发图按钮 —— 判定只在一处（后端），
    界面复制一份就是第二个事实面。口径是用户选的"只拦确定的否"（误杀一个能看图的模型，
    比多花一次 400 往返严重）。文档以前写"决定发图按钮"是超前描述，已按现状收回。
    这样"切到某个云端 VLM"
    对任意角色都能用，不必为绕模型缺陷去建特殊角色（用户 2026-09-19：能力是模型的属性）。
13. **轮次事件名是跨语言线协议**：内核侧唯一声明处是 `core/turn.py` 的 `EVENT_TYPES`
    （每个事件类自带 `sse_type`，帧化直接读它，不存在第二份字符串清单），前端侧是
    `api.ts` 的 `ChatEvent` 联合。两者由 `tests/unit/test_frontend_contract.py` 做双向差分
    —— 改一边不会让另一边编译失败，症状只是"那一类东西从此不显示"。
14. **一轮对话的编排不属于 HTTP 层**：跑图、流式审核、文本对账、失败翻译全在 `core/turn.py`，
    投送方式（SSE / 桌宠原生事件 / 脚本直取）是宿主的事。

## 6. 安全模型总纲（贯穿所有里程碑）

- **fail-closed 贯穿**：认证、guard、工具白名单、路径边界、审批默认（run_command 默认手动批准）。
- **路径边界**：任务目录外读写一律拒绝（`_resolve_within`）；run_command cwd 必落任务目录内。
- **联网边界**：联网总闸 + 域名白名单 + web_fetch 逐跳 SSRF 校验；未配 key 不外发。
  `image_search`（SauceNAO 反向图搜）同受联网总闸管，未配 `SAUCENAO_API_KEY` 时返回可读提示、
  **绝不静默上传**用户图片（与云端 OCR 同一"图片外发需显式配置"义务）。
- **审批共用确认 UI**：命令审批（B/S 确认卡，C/S 系统弹窗）；批准一次跑 N 遍被结构禁止（回放）。
  **批准还要持有凭据**：每条待批由读侧下发一次性 `decide_token`（30 分钟过期、决定后清空），
  `decide` 缺 / 错 / 过期 = 403。它不是登录（单机形态本来就不登录），而是"这一条你确实看到过"
  —— 于是"猜自增 id 就批准"和浏览器里的跨源盲 POST 都不成立（读不到响应就拿不到令牌）。
- **不做 Agent 自扩权，但允许 operator 主动接入**：红线是"运行中的 LLM Agent 自己启用/安装
  能力"——绝不允许（启停/接入从不暴露为 LLM 工具，见 `domains/registry.py`）。**用户在设置里
  主动接入 MCP server 是合法的 operator 动作**：`/api/mcp/servers` CRUD（仅 http 传输；URL 由
  operator 主动填故本机/内网/公网均可——"仅公网"的 SSRF 边界只用于模型给的 URL，如 web_fetch；
  headers 只写不回读掩码；全程审计；启停热重载；**添加即自动测、连不上仍保存但标红**）。
  env `MCP_SERVERS` 与运行时 `mcp_server` 表并存合并（表覆盖同 id）。**MCP 是可选扩展层**
  （与 OCR/RAG 同层）：需 `pip install -r requirements-mcp.txt`，未装时接入/测试给可操作提示。
  插件同理：启停是 operator 动作，不做 LLM 自助安装。
- **数据保护**：LangSmith/云端可观测默认关闭；健康数据不外发除非显式配置。

## 7. 质量与门禁纪律

- 分层门禁（`scripts/gate.py`）：**平时迭代 `--fast`（≈1 分钟：ruff + mypy + 单测 + 一致性）**；
  仅提交/发布前跑**全量**（+ 覆盖率门槛 + 前端 test/build + 真机冒烟，约 5~6 分钟）。
  更快的反馈是只跑相关测试文件。
- 提交前：Conventional Commits（`feat`/`fix`/`docs`/`test`/`refactor`/`chore`）；不提交 `.env`、
  真实数据、任何密钥；演示数据全部虚构。
- 文档纪律：见 [`开发流程.md`](开发流程.md)——每个能力先在设计文档留痕再实现，实现后回写覆盖矩阵。
