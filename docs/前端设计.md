## 1. 分层与组件约定

```
frontend/src/
  api.ts                 # 唯一数据出口：所有后端调用集中于此，页面不各自 fetch
  App.tsx                # 自研 Hash 路由（不用 react-router），6 页签全 React.lazy 分包 + 错误边界
  index.css              # Tailwind v4 + 语义化组件类 + @custom-variant dark
  components/
    ui/                  # 纯展示、零业务：Button/Card/Tag/Switch/PageHeader/Notice + barrel
    Toast.tsx            # toast 状态提示（自动消失，多条不互相覆盖）
    chat/                # 对话专属：ThinkingPanel / ProcessPanel / ToolStepCard / Markdown
    ApprovalPanel.tsx    # 命令审批抽屉（C·§6.2）
    ReachoutPanel.tsx    # 主动开口收件箱（B/C）
  pages/                 # 业务编排：Chat/Data/Knowledge/Roles/Plugins/Settings
```

**原则**：`components/ui/` 只做展示、零业务；页面负责编排；数据只从 `api.ts` 出。新代码必须
复用 `ui/`，旧代码按页面渐进迁移。

**技术栈**：Vite 构建 + `tsc --noEmit`；Tailwind CSS v4（无 config 文件）；`dist` 有意入库
（clone 后无 node 也能演示，FastAPI 静态托管，API 路由优先注册）。

## 2. 深色模式与响应式基线

- **深色**：Tailwind v4 用 `@custom-variant dark (&:where(.dark, .dark *))`（非 v3 的
  `darkMode:"class"`）；`useTheme` 读写 `localStorage` + 切换 `documentElement.classList`，
  初始跟随 `prefers-color-scheme`。
- **响应式（移动优先降级）**：App 导航 `w-52`、ChatPage 会话栏 `w-64` 在 `<768px` 折叠为
  off-canvas 抽屉（`max-md:fixed` + 汉堡 + 遮罩，选中自动关）；表格外层 `overflow-x-auto`；
  留白 `p-4 md:p-6`。两个抽屉共用同一模式。
- **性能**：路由级代码分割（首屏只加载对话页）；`useMemo` 派生；checkpoint 回放是对话历史唯一真相。

## 3. 信息架构（6 页签 + 2 面板）

顶层把三件最易混的事拆到各自位置，**数据**与**知识库**都不再寄居：

| 位置 | 职责 | 对应端点组 |
|---|---|---|
| **对话** | 会话列表/续聊/删除、SSE 流式 + 工具过程可视化、上传、增强提示词、上下文使用率 | sessions / chat / prompt / uploads / model-providers |
| **数据** | 领域数据唯一归属地，按域分组：新增/修正/删除/抽取/筛选 | records / domains |
| **知识库** | RAG 内核能力独立成页：作用域/来源/分块/嵌入器/检索延迟/重建/上传回收 | knowledge / rag-metrics / uploads |
| **角色卡** | 人格 + 权限（白名单/作用域/范例/模型覆盖）+ **主动开口四开关** | roles / tools-catalog |
| **插件** | 只做能力开关（领域插件启停 + 工具清单），**不含数据、不做运行时安装** | plugins / tools-catalog |
| **设置** | 6 个子页签：通用（主题/外观 + **记忆卡**）· 模型（后端 CRUD/热重建/能力位）· 服务（用例注册/回退链）· **扩展**（MCP 接入 + 模型后端连通性自检）· 运行环境（在线编辑热生效，含任务目录/联网/思考/超时预算/主动开口/命令执行等组；OCR·RAG 组只剩只读的部署项）· 审计 | settings/* · runtime · memory · audit · workspace · **mcp** |
| 面板·**审批** | 命令审批入口（侧栏红点 10s 静默轮询）+ 审批抽屉 | approvals |
| 面板·**主动** | 角色主动开口收件箱（按角色筛选 + 待消费文件变化数；条目点进去 = 该角色的主动会话） | reachouts |

## 5. 明确不做（沿用既有取舍）

- 插件/MCP 的**界面动态安装**（运行时让 Agent 自扩权 = 破坏权限边界；能力靠声明式接入）。
- 多租户登录界面（v1 单用户演示；多人属长期里程碑）。
- 移动端**原生 App**：只做响应式 Web。
- 运行时主题切换动画。

## 6. 已知小缺口（按需，非阻塞）

- ChatPage.tsx 体量大，可拆 `useChatStream`/`useSessions` hooks（纯可维护性）。
