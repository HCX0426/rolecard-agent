> 这棵树在 09-28 之前漏了 12+ 个真实存在的文件（`R28-41`）——漏掉的恰好是最新那两条线
> （同步/身份、桌宠形象）。**判断"某个界面存不存在"时不要信这张表**，它只说约定；
> 底下的矩阵才是逐条对过端点的，两者不一致时以 `frontend/src` 实际调用为准。

**原则**：`components/ui/` 只做展示、零业务；页面负责编排；数据只从 `api.ts` 出。新代码必须
复用 `ui/`，旧代码按页面渐进迁移。

**不可用控件的三档口径**（详见 `docs/archive/模型接入设计稿.md` §4）：本形态永远不可能用 → **整条不出现**；
暂时不可用但有恢复路径 → **出现 + 禁用 + 一行说明怎么恢复**（走 `ui/Button` 的 `disabledHint`，
禁用态样式与说明只在 `ui/Button` 里实现一份；`title` 在禁用按钮上 Chromium 不弹，别用它承载说明）；
探测不到 → **不禁不拦**，如实显示"未知"。

**技术栈**：Vite 构建 + `tsc --noEmit`；Tailwind CSS v4（无 config 文件）；`dist` 有意入库
（clone 后无 node 也能演示，FastAPI 静态托管，API 路由优先注册）。
**入库就意味着它是一份要同步维护的事实**：改 `frontend/src` 必须把重建出的 `dist` 放进同一个
提交 —— 随包后端托管的就是这份 dist，漏一次就是"源码是新的、clone 与安装包是旧的"，而且不报任何错。
全量门禁在 `npm run build` 之后比对 `frontend/dist` 与仓库，不一致就红（`scripts/gate.py`）。

## 2. 深色模式与响应式基线

- **深色**：Tailwind v4 用 `@custom-variant dark (&:where(.dark, .dark *))`（非 v3 的
  `darkMode:"class"`）；`useTheme` 读写 `localStorage` + 切换 `documentElement.classList`，
  初始跟随 `prefers-color-scheme`。
- **响应式（移动优先降级）**：App 导航 `w-52`、ChatPage 会话栏 `w-64` 在 `<768px` 折叠为
  off-canvas 抽屉（`max-md:fixed` + 汉堡 + 遮罩，选中自动关）；表格外层 `overflow-x-auto`；
  留白 `p-4 md:p-6`。两个抽屉共用同一模式。
- **性能**：路由级代码分割（首屏只加载对话页）；`useMemo` 派生；checkpoint 回放是对话历史唯一真相。
