| 项 | 要求 |

## N4 · 层二：找值（优化，两视角）

**开发者层（agent D）**

- 改一个后端字段要动几处？已知至少四处：`schema.sql` + `_migrate` +
  `migrate_to_provider_layers` 内联 DDL + `model_settings` 的 SELECT。请**实测数一遍**并给收敛方案。
- 测试跑一轮的时长分布（fast 108s 里 pytest 占 ~95%）；哪些用例是"每次都跑但不太可能红"的。
- 门禁抓不到什么：产物新鲜度、dist 同步靠人记、散文引用刚补上、`build/baseline.json` 没有进门禁。
- 取证工具链：`persona_chat_sim` / `persona_ab` / `scratch_db` / `baseline` 的接缝是否重复。

**使用者层（agent E）**

- **首字延迟**与感知速度（分档：本地 8B / 云端 flash / 云端 VL）。
- **主动开口的命中率现在没有任何指标在量** —— 她冒出来的那句你想不想回，是这款产品成败的核心，
  却只有条数没有质量。这一条要给出可测口径的候选，不接受"加个反馈按钮"这种答法。
- 记忆面板能不能**改一条**而不是清池重抽（§12.5 的旧痛点）；`importance` 三档上线后真实使用率。
- 桌宠手感还剩什么（含"开机时鼠标已经压在色片上，第一次点不点得动"这条未验项）。
- 跨窗口未读 10s 轮询：值得为它做多快？给代价而不是立场。
