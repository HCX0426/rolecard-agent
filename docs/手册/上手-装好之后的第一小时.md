# 上手：装好之后的第一小时

> 面向：用 Windows 安装包装好 rolecard-agent 的人。开发者视角的快速开始（venv/pip）在
> README；这一页只讲"装完之后"。

## 0. 装的时候发生了什么

- 程序装进系统程序目录；**你的数据**落在 `%LOCALAPPDATA%\rolecard-agent`（下称"数据根"）。
  对话、记忆、知识库、桌宠形象全在这里——备份/搬走只认这个目录（见《数据与隐私》页）。
- 卸载程序**故意不删**数据根：对话与体检记录是你自己决定去留的事。
- 后端日志每次启动覆盖写在 `%APPDATA%\rolecard-agent\backend.log`；壳自己追加写同目录的 `shell.log`。

## 1. 第一次启动

- 双击 rolecard-agent 图标（或开始菜单）。壳启动后会自动拉起随包的后端（约几秒），
  然后打开控制台窗口。右下角托盘里有一个图标：右键它有"检查更新 / 开机自启 / 退出"等项。
- 如果窗口没出现：先看托盘是否已在运行；再看 `backend.log` 最后一行（那里会说"谁没起来"）。

## 2. 配一个模型后端（必做）

没有模型后端就没有对话。进 **设置 → 模型**，配其中一个：

| 类型 | 填什么 | 适合 |
| --- | --- | --- |
| SiliconFlow / DeepSeek / 其他 OpenAI 兼容端点 | provider、base_url、model、api_key | 有云端 key 的（**推荐第一口**：响应快，首字约 1~3 秒） |
| Ollama（本机） | base_url 指向本机 Ollama | 本机有大显存、愿意等（本地模型首字可能 10 秒以上，那多半是"思考"过程，对话页可展开看） |

- api_key **只写不回读**：保存后界面永远只显示掩码，这是有意的。
- 可以配多个后端并设"默认"与回退链；某一家挂了会按链降级并在回答上注明由谁答的。

## 3. 第一张角色卡

- 内置只有一张「通用助手」。**角色卡页 → 导入**可以直接吃 SillyTavern 的角色卡文件
  （PNG 内嵌卡或 JSON；V1/V2/V3 都认）。导入完界面对账单会告诉你哪些东西没带进来
  （世界书/标签走知识库页，不静默丢）。
- 自己建：角色卡页 → 新建。人设（system_prompt）、温度、工具白名单、知识作用域都在这里。
- 每张卡行上有三个常用动作：**编辑 / 事件簿 / 导出**。导出会把卡存成 ST V2 JSON 文件——
  **记忆默认不跟着走**，只有你在确认框里选"带记忆导出"才会带上置顶且未失效的那几条。

## 4. 桌宠

- 托盘菜单可以把桌宠窗唤出来。桌宠窗有自己的对话输入；她在屏幕上走动，鼠标靠近有反应，
  拖到屏幕边缘会趴边。
- 桌宠说的每一句在**对话页签同步可见**；换角色用桌宠面板上方的下拉框。

## 5. 让她主动找你（可选，默认关）

- 主动开口是 opt-in：**角色卡页**有全局总闸，每张角色卡自己还有"是否允许主动"开关。
- 打开后她会按时机来收件箱/桌宠给你留话；所有主动说的话在对话历史里都在，删掉收件箱
  条目不会让她失忆（那是她的会话记录，删会话才会）。

## 6. 第一小时结束时的检查单

- [ ] 设置→模型里有一个能答话的后端（对话页发一句"你好"有回应）
- [ ] 有至少一张自己的角色卡（导入或新建）
- [ ] 知道托盘菜单与桌宠怎么唤出
- [ ] （可选）主动开口已按角色打开
- [ ] 知道《常见问题与故障排查》这一页在哪
