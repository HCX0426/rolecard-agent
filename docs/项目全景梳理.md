## 一、技术栈总结

### 后端（Python 3.13，`src/rolecard_agent/`）

| 层 | 技术 | 说明 |
|---|---|---|
| API 框架 | FastAPI + uvicorn | 同步端点为主（线程池执行）；上传端点刻意同步避免阻塞事件循环 |
| Agent 编排 | LangGraph 1.2.11 + LangChain 1.4.0 | 两节点循环（model↔tools）+ SQLite Checkpointer；必须成对锁版本 |
| 模型接入 | langchain-ollama / langchain-openai（经 `init_chat_model`） | 多后端同构（本地 Ollama + 任意 OpenAI 兼容云），回退链 ≤2，超时 120s |
| 业务持久化 | SQLite（WAL + FK + busy_timeout，`ThreadLocalConnection` 按线程分发） | 单文件库 `data/sqlite/app.db`，业务表 + checkpoint + 审计 |
| 向量检索 | Chroma（PersistentClient）+ 自研 HashEmbedder / SiliconFlow bge-m3 / 重排 | 一个作用域一个集合；每源幂等重建 |
| 校验/配置 | Pydantic v2 + 自研 `Settings.from_env`（环境变量驱动） | 依赖单一事实来源 pyproject.toml，requirements*.txt 是镜像 |
| 文档摄取 | pypdf（PDF）+ 标准库 zipfile/ElementTree（OOXML）+ 可插拔 OCR | PaddleOCR 在**独立 venv 子进程**（数据不出本机）；云端 OCR 需显式 key |
| 可观测 | 自研 Tracer 门面（JSON lines，默认键控脱敏）+ 审计表（actor/action/target） | langsmith/langfuse 为预留后端（未实现，降级留痕） |
| 质量工具 | pytest+pytest-cov（291 用例，阈值 85%）· ruff · **自研 check_consistency**（文档↔代码 23 项断言）· mypy（已配置**未启用**） | 测试全离线铁律：LLM 一律注入脚本替身 |

### 前端（`frontend/`，React 18 + TypeScript 5.6）

| 项 | 技术 | 说明 |
|---|---|---|
| 构建 | Vite 6 + `tsc --noEmit` | dist 产物**有意入库**（clone 后无 node 也能跑） |
| 样式 | Tailwind CSS v4（`@custom-variant dark`） | 深色模式全量 |
| 路由 | **自研 Hash 路由**（App.tsx，6 页签全 lazy） | 不用 react-router；深链 `#/roles` 等 |
| 测试 | vitest（12 条，api 层契约） | node 环境 mock fetch；CI 前端 job 会跑 |

### 运行依赖（外部）

Ollama（便携版，`D:\code\Ollama`）+ `qwen2.5vl:7b`（Q4 ~4.5GB，对话/抽取/图片直读三合一，8GB 显存单模型常驻）。

## 二、部署方式与运行环境（现状 + 计划）

**现状（本机运行形态）**：
- `scripts/run_api.py` 起 uvicorn 单进程，绑 127.0.0.1:8000；前端 dist 由 FastAPI 静态托管（API 路由优先注册）
- 数据落 `data/`（SQLite + Chroma + uploads），已 gitignore；演示身份单用户
- 认证 `AUTH_MODE=off`（本地零配置）；模型默认 `local`（Ollama 127.0.0.1:11434）

**v2.4 计划（README / 实施计划已定，未执行）**：
1. **Docker**：`python:3.13-slim` 镜像（已含 requirements-rag 修复），dist 打进镜像，数据挂卷 `rolecard-data:/app/data`；**未实机 build 验证**（本机无 docker）
2. **认证切换**：部署时 `AUTH_MODE=on` + `AUTH_CREDENTIALS`/`AUTH_API_KEYS`（用法已写入 .env.example）
3. **模型侧两形态**（同一份代码只改配置）：演示期可内网穿透回本机 Ollama；稳定版云服务器 + 云端 API 后端（MODEL_BACKENDS 切换）
4. **CI**：GitHub Actions（后端 lint+test+覆盖率 85%+一致性 / 前端 test+build）——⚠️ 仓库目前**无远端，CI 从未真实执行过**
5. 未规划项（部署前需补）：TLS/域名、限流、Docker 实机验证
